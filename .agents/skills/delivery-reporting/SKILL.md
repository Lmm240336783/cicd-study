# Delivery Reporting

## When To Use

使用此 skill 当：

- 用户要求说明“改了什么、下一步做什么、影响范围、已验证什么”。
- 任务跨多个文件、模块、阶段或多轮验证。
- 新增、删除或调整功能、入口、接口、依赖、目录、长期文档或验收标准。

## Checkpoint

阶段性汇报保持简短，包含：

- 本次完成。
- 影响范围。
- 已验证。
- 文档同步：已同步或无需同步及原因。
- 下一步。

## Documentation Sync

- 每个项目都维护 `docs/<project>/project-directory-structure.md` 作为项目大体结构文档。
- 每个项目都维护 `docs/<project>/project-quick-brief.md` 作为项目功能块与快速阅读摘要。
- 新增功能、入口、目录、接口、依赖或验收标准变化时，先同步对应项目文档再收尾。
- 纯格式化、拼写、临时调试且不改变长期事实时，可不更新项目文档，但最终说明原因。
