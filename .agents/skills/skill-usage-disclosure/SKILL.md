# Skill Usage Disclosure

## Rule

1. 只要本回合启用了任何项目 skill，就在开始阶段或关键节点简短说明。
2. 说明最关键的 1 到 3 个 skill 即可，不写成长篇汇报。
3. 如果没有启用项目 skill，不要硬报。

## Example

```text
这次会用 `encoding-guard` 和 `delivery-reporting`：前者检查中文文档编码，后者处理文档同步与收尾说明。
```
